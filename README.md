# Asteria Nuclear Thermal Propulsion - GitHub Pages deck

## Deploy
1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets/` folder.
3. In GitHub, open **Settings -> Pages**.
4. Set source to the repository branch and root folder.
5. Open the Pages URL after deployment.

## Controls
- Right / Space / PageDown: next slide
- Left / PageUp / Backspace: previous slide
- Home / End: first or last slide
- F or fullscreen button: fullscreen

Names from the original PDF-only separator slides were removed.
